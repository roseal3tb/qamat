# Qamat Launchpad

Build the official website for "قامات | QAMAT"

Build a complete, premium, modern Arabic RTL website for the initiative "قامات | QAMAT".

The website must be fully implemented, responsive, interactive, and production-ready.

Do NOT create a generic landing page.

The website should feel like a high-end Saudi youth initiative website, with a strong visual identity, storytelling, sophisticated animations, and an editorial-style layout.
